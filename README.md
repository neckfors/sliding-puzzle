# Shuffle 15

A tactile 15-puzzle sliding tile game (3x3, 4x4 and 5x5 grids). Single HTML file, installable as an app.

Play it: https://neckfors.github.io/sliding-puzzle/

## Offline and updates

The game works offline after the first visit. When a new version is published, a bar at the top says "New version available" with an Update button; nothing reloads until you tap it. The app checks for updates when you return to it and every 30 minutes. The version number is shown in the install help dialog. (Maintainers: bump VERSION in sw.js on every release.)
